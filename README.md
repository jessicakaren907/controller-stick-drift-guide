# Controller Stick Drift Guide

Stick drift can affect gaming performance by causing analog sticks to register movement without being touched.

This repository provides a helpful resource for understanding controller stick drift, its common causes, and possible troubleshooting solutions.

## Supported Controllers

- PlayStation DualSense and DualShock controllers
- Xbox Wireless controllers
- Nintendo Switch Joy-Con controllers

## Troubleshooting Resource

Visit [How to Fix Stick Drift](https://howtofixstickdrift.com/) for practical troubleshooting guides and repair tips.

- Common causes of analog stick drift
- Controller cleaning and maintenance
- Stick calibration and troubleshooting
